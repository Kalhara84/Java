# Java Programming - BASICS

A comprehensive collection of Java programming exercises, tutorials, and projects covering fundamental to intermediate concepts.

## 📚 Overview

This repository contains Java learning materials organized chronologically, including basic programming concepts, object-oriented programming, GUI development, and database connectivity.

## 🚀 Getting Started

### Prerequisites
- **Java Development Kit (JDK)**: Version 8 or higher
  - Download from [Oracle](https://www.oracle.com/java/technologies/downloads/) or use [OpenJDK](https://openjdk.org/)
  - Verify installation: `java -version` and `javac -version`
  
- **Integrated Development Environment (IDE)** - Choose one:
  - **Eclipse**: Great for enterprise Java development
  - **NetBeans**: Excellent GUI builder (Matisse)
  - **IntelliJ IDEA**: Modern, intelligent IDE
  - **VS Code**: Lightweight with Java extensions
  
- **Database Systems** (Optional):
  - **MySQL**: For MySQL connectivity examples
    - Download [MySQL Community Server](https://dev.mysql.com/downloads/mysql/)
    - MySQL Workbench for database management
  - **SQLite**: For lightweight database examples
    - No installation required - embedded database
    - SQLite JDBC driver included in projects

### Setting Up Your Environment

#### 1. **Install JDK**
```bash
# Windows (PowerShell)
# Download installer from Oracle website and run

# Verify installation
java -version
javac -version
```

#### 2. **Set Up IDE**
- **For Eclipse**: Import existing projects from the `eclipse/` folder
- **For NetBeans**: Open projects from `NetbeansIDEGUITutorial/` folder
- **For VS Code**: Install "Extension Pack for Java" from Microsoft

#### 3. **Configure Database Drivers** (if needed)
- Download MySQL Connector/J for MySQL projects
- SQLite JDBC driver: `sqlite-jdbc-<version>.jar`
- Add JAR files to project classpath


#### **Issue: GUI window not appearing**
- Ensure you're running on a system with graphical display
- Check if main method creates and shows the frame

- Verify database server is running

- Ensure JDBC driver is in classpath
